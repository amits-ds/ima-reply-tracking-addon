על הפרויקט המידע שלכם התקנה איך משתמשים
English

מהדורת פיילוט. אם משהו בעמוד לא ברור או לא תואם את מה שאתם רואים, זה בדיוק המשוב שאנחנו צריכים.

התקנת התוסף

כ-10–15 דקות, במחשב, פעם אחת. מדביקים פקודה אחת, מתחברים לגוגל, ואז עושים שתי לחיצות שגוגל מחייבת לעשות בעצמכם.

כל השלבים שבעמוד, על המסך, בפחות משלוש דקות, עם קריינות וכתוביות. החשבון, הקוד והשמות הם לדוגמה.

לפני שמתחילים

  • מחשב Windows או Mac עם Chrome או Edge. גם ההתקנה וגם השימוש בתוסף נעשים במחשב: דפדפן בטלפון לא מציג תוספים, ואפליקציית Gmail בטלפון מציגה לכל היותר כרטיס קטן ליד מייל פתוח.
  • חשבון ה-Gmail שממנו אתם כותבים להר"י. אם יש לכם כמה חשבונות, השתמשו בו בכל השלבים.
  • פקודת ההתקנה שהקבוצה שיתפה איתכם (אותה פקודה לכולם; אין קוד אישי).
  • כדאי לקרוא קודם את המידע שלכם: שם מוסבר מה התוסף שולח ומה לא.

שלב 1: הרצת תוכנת ההתקנה

  1. פתחו חלון פקודות. ב-Windows: לחצו על התחל, הקלידו PowerShell ופתחו אותו. ב-Mac: לחצו ⌘+רווח, הקלידו Terminal ופתחו אותו.
  2. הדביקו את פקודת ההתקנה בחלון הזה ולחצו Enter. העתיקו את כל הפקודה, בדיוק כמו שהיא.
  3. התחברו לגוגל. נפתח חלון בדפדפן. בחרו את חשבון ה-Gmail שממנו אתם כותבים להר"י. גוגל מציגה מסך של כלי בשם clasp עם תשע הרשאות: השאירו את כולן מסומנות ולחצו Allow.
    clasp הוא כלי של גוגל ליצירת פרויקטים של Apps Script. תוכנת ההתקנה משתמשת בו רק כדי ליצור את העותק שלכם של התוסף, ומבטלת את ההתחברות בסוף. היא לא קוראת את הדואר שלכם. מה תוכנת ההתקנה עושה
  4. רק בחשבון חדש: נפתח עמוד שמבקש להפעיל את Google Apps Script API. הפעילו וחזרו לחלון הפקודות. לפעמים לוקח לגוגל כמה דקות לזהות את השינוי; תוכנת ההתקנה ממשיכה לנסות בעצמה.
  5. כשתוכנת ההתקנה כותבת Done, היא פותחת בדפדפן את פרויקט התוסף החדש שלכם. אפשר לסגור את חלון הפקודות.

גוגל תשלח לכם מייל בנוסח "You allowed clasp access…", ומאוחר יותר הודעה דומה על העותק שלכם. שתיהן רגילות.

שלב 2: שתי הלחיצות שגוגל מחייבת

  1. התקנה. בעמוד הפרויקט שנפתח: לחצו על הכפתור הכחול Deploy, אחר כך Test deployments, ואז Install. אם נפתח חלון קטן, המתינו כמה שניות עד שייטען.
  2. אישור. פתחו את Gmail ולחצו F5 לרענון. פתחו מייל כלשהו ולחצו על סמל התוסף החדש בחלונית שבצד. לחצו Authorize access ובחרו את החשבון שלכם.
    • גוגל תציג "Google hasn't verified this app". זה צפוי: זה העותק האישי שלכם, לא אפליקציה מחנות. לחצו Advanced, ואז Go to … (unsafe).
    • לחצו Allow. למה משמשת כל הרשאה

אם החלונית נשארת ריקה אחרי האישור: פתחו את התפריט (⋮) בראש החלונית ובחרו Refresh, או רעננו את Gmail (F5).

שלב 3: מסכי הפתיחה

בפעם הראשונה שפותחים את התוסף, הוא שואל ארבעה דברים קצרים. בשלבים שהם רשות יש כפתור דילוג.

  1. שפה והשם שלכם. השם משמש רק לחתימה במיילים שתכתבו דרך התוסף.
  2. קצת עליכם (רשות): שלב בקריירה, תחום, מקום עבודה. בכל שאלה אפשר לבחור "לא רוצה לציין". למה אנחנו שואלים
  3. הצעות Gemini (רשות). בזמן הפיילוט אנחנו ממליצים לדלג על השלב הזה. עוד
  4. ההיסטוריה שלכם. אם זו ההתקנה הראשונה שלכם, לחצו זו הפעם הראשונה שלי. אם השתמשתם בתוסף בעבר, לחצו שחזור ההיסטוריה שלי.

זהו. מעכשיו התוסף בודק את תיבת הדואר פעם ביום בעצמו. הבא: איך משתמשים.

עוד

הוספת מפתח Gemini (רשות)

התוסף עובד במלואו גם בלי Gemini. עם מפתח משלכם, Gemini מציע דירוג לכל תשובה; ההחלטה הסופית תמיד שלכם. קראו קודם מה Gemini מקבל.

  1. פתחו את aistudio.google.com/apikey, התחברו, לחצו Create API key והעתיקו את המפתח.
  2. בתוסף פתחו את התפריט (⋮), בחרו הגדרות, וליד Gemini לחצו מפתח.
  3. הדביקו את המפתח בשדה מפתח Gemini API ולחצו שמירה.
אם תוכנת ההתקנה לא עובדת: התקנה ידנית

לא צריך להירשם קודם: החשבון שלכם מצטרף לקבוצה אוטומטית בפעם הראשונה שהתוסף פונה לשרת של הקבוצה. ואז:

  1. פתחו פרויקט Apps Script חדש, מחוברים בחשבון שממנו אתם כותבים להר"י.
  2. לחצו על גלגל השיניים (Project Settings) בצד וסמנו Show "appsscript.json" manifest file in editor. חזרו לעורך (הסמל <>).
  3. בעמוד הגרסה האחרונה פתחו את Code.gs ואת appsscript.json. העתיקו את כל הטקסט של כל קובץ במקום הקובץ באותו שם בעורך, ולחצו Save (סמל הדיסק).
  4. המשיכו בשלב 2 ובשלב 3 למעלה.
משהו לא עבד
  • תוכנת ההתקנה כותבת שהשרת לא קיבל את החשבון שלכם. בדרך כלל נבחר חשבון Google אחר: הריצו שוב את תוכנת ההתקנה ובחרו את החשבון שממנו אתם כותבים להר"י. אם זה חוזר, כתבו לנו.
  • תוכנת ההתקנה ממשיכה לחכות ל-"Google Apps Script API". ודאו שהמתג בעמוד הזה מופעל, באותו חשבון שבו התחברתם. לפעמים לוקח לגוגל כמה דקות.
  • לא רואים את סמל התוסף ב-Gmail. פתחו מייל (לא רק את תיבת הדואר) וודאו שהחלונית שבצד פתוחה (החץ הקטן בקצה המסך). בדקו שה-Install בשלב 2 הסתיים ב-"Installed", ורעננו את Gmail.
  • הודעת שגיאה שספרייה (library) חסרה, או שאין לכם הרשאה. החשבון שלכם לא קיבל גישה לקבצים של הקבוצה. כתבו לנו עם כתובת ה-Gmail שלכם.
  • בהגדרות מופיעה בעיה בהעלאה עם "not authorized". ההתחברות פגה, או שהחשבון שלכם הוסר מהקבוצה. הרישומים נשמרים אצלכם ונשלחים אוטומטית כשזה מסתדר. כתבו לנו.
  • בהגדרות כתוב שהחברות שלכם מושהית לבדיקה. זה קורה אוטומטית אחרי פעילות חריגה: הרבה מאוד רישומים ביום אחד, או התוסף מותקן ביותר מ-5 מחשבים בתוך 90 יום. מנהלי הקבוצה בודקים את זה; הרישומים נשמרים אצלכם ונשלחים כשההשהיה מוסרת. אפשר לכתוב לנו כדי להסביר.
  • התוסף מבקש עדכון. ראו עדכונים. שום דבר לא הולך לאיבוד בינתיים.

מחשב חדש, או התקנה מחדש

הריצו שוב את פקודת ההתקנה (אותה פקודה כמו בפעם הראשונה). כל התקנה במחשב נוסף נחשבת עותק חדש של התוסף; יותר מ-5 בתוך 90 יום משהים את החברות לבדיקה. במסך הפתיחה האחרון לחצו שחזור ההיסטוריה שלי, או מאוחר יותר: הגדרות ← מתקדם ← שחזור ההיסטוריה ממאגר הנתונים. ההתכתבויות שכבר עקבתם אחריהן חוזרות, כך שלא תישאלו עליהן פעמיים. מפתח ה-Gemini, השם שלכם ובחירות הסגנון לא משוחזרים: הזינו אותם שוב.

עדכונים

כמעט כל עדכון מגיע אליכם מעצמו, בלי שתצטרכו לעשות דבר. אם החלונית נראית ישנה אחרי עדכון, בחרו Refresh בתפריט החלונית (⋮).

לעיתים רחוקות משתנה גם הקובץ של התוסף עצמו. אז התוסף מציג הודעה עם קישור להורדה. הדרך הפשוטה לעדכן היא להריץ שוב את פקודת ההתקנה; היא מעדכנת את העותק הקיים שלכם.

הסרת התוסף

פתחו את פרויקט התוסף שלכם (script.google.com, "IMA Reply Tracking"), ולחצו Deploy ← Test deployments ← Uninstall. אפשר גם למחוק את הפרויקט. מאותו רגע לא נשלח דבר. רישומים שכבר נשלחו נשארים במאגר הנתונים החתום; ראו הפסקה, והוצאת הרישומים שלכם.

מה תוכנת ההתקנה עושה, ואיך לבדוק

תוכנת ההתקנה היא שלושה קובצי טקסט פשוטים שאתם או כל אחד אחר יכולים לקרוא. היא כותבת רק לתיקייה אחת בתיקיית הבית שלכם (.ima-reply-tracking), לא מתקינה דבר ברמת המערכת, אף פעם לא קוראת את הדואר שלכם, ומבטלת את ההתחברות לגוגל בסוף. כל קובץ נבדק מול טביעת אצבע שפורסמה לפני שהוא רץ.
